Server Storage Extension

Docs for the Scratch/TurboWarp extension that syncs project data to ikelene.net.

Generate API Key

Getting started

  1. Click Generate API Key above, give it a friendly name, and copy the key it gives you.
  2. In your Scratch/TurboWarp project, load the Server Storage extension and use the set api key [APIKEY] block with your key.
  3. Use store [VALUE] as [KEY] / get [KEY] to read and write data, or switch editing modes below for bulk work.

Live vs. Cached editing

The extension has two editing modes, switched with the switch to [MODE] editing block. Check the active mode with current editing mode.

Live mode (default)

Every get/store/delete block talks to the server directly, in real time.

  • Always up to date, no stale data
  • No extra steps needed
  • Slower — each block call is a network request

Local (cached) mode

Data is pulled into a local cache once, then reads/writes hit that cache instantly.

  • Fast — no network delay per block
  • Requires download all keys to local cache first
  • Changes stay local until push local changes to server
In cached mode, nothing you write is saved to the server until you run push local changes to server. If your project closes before pushing, those changes are lost. Live mode never has this risk.
